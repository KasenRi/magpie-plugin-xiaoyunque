# 小云雀（XiaoYunQue）提示词与多模态创作模式指南

## 1. 五种创作模式（`mode`）选型与参数映射

| 模式 (`mode`) | 适用场景 | 必填素材参数 | 底层协议行为与关键约束 |
| :--- | :--- | :--- | :--- |
| `t2v` | 纯文生视频、空镜、氛围过渡镜 | 仅 `prompt` | 不传任何图片/视频/音频；注意 `happyhorse-1.1` 不支持 `adaptive` 比例（需显式指定 `16:9` / `9:16` 等） |
| `first_last_frame` | 精确锁死首帧构图/人货比例，或首尾两帧平滑过渡 | `first_frame`（可选加 `last_frame`） | 插件自动设置 `generate_type: 1`；`happyhorse-1.1` **不支持**此模式；`Seedance_1.0_fast` 仅支持单首帧（禁传 `last_frame`） |
| `reference` | 多图角色+场景+产品融合、参考动作视频或卡点音频 | `reference_images` / `reference_videos` / `reference_audios` 至少一项 | 提示词中用 `[@图片1]`、`[@图片2]`、`[@视频1]`、`[@音频1]` 精确指代；`Seedance_1.0_fast` 不支持此模式 |
| `edit` | 对已有视频局部修改服饰、背景、天气或替换主体 | `reference_videos`（被编辑原片）+ 可选 `reference_images` | **仅 `Seedance_2.5` 支持**（`Seedance_2.5_draft` 线上已关闭 `video_edit`）；提示词写清保留什么、把 `[@视频1]` 中的什么改成什么 |
| `extend` | 将已有镜头自然向后续拍延长 | `reference_videos`（待续拍原片） | 仅 `Seedance_2.5` 与 `Seedance_2.5_draft` 支持；提示词描述紧接原片末尾发生的后续动作 |

---

## 2. 多模态引用语法（`[@图片N]` / `[@视频N]` / `[@音频N]`）

在 `mode: "reference"`、`edit` 或 `extend` 下，小云雀按传入数组的先后顺序（从 `1` 开始编号）绑定素材占位符：
- `reference_images: [imgA, imgB]` → 提示词中的 `[@图片1]` 对应 `imgA`，`[@图片2]` 对应 `imgB`。
- `reference_videos: [vidA]` → 提示词中的 `[@视频1]` 对应 `vidA`。
- `reference_audios: [audA]` → 提示词中的 `[@音频1]` 对应 `audA`。

**推荐写法模板**：
- **角色 + 产品同框种草镜**：
  > 手机拍摄，固定机位，镜头不推不拉不移动，柔和室内侧窗自然光。`[@图片1]`中的年轻女性保持相同服装与发型，坐在浅色木桌旁，双手自然拿起桌上`[@图片2]`中的保湿面霜瓶（瓶高约 8 cm，远小于手掌），轻轻拧开瓶盖，低头看手里的面霜瓶，不看镜头。背景简洁无杂物，画面无文字无水印。
- **视频编辑（`Seedance_2.5` + `mode: "edit"`）**：
  > 保持`[@视频1]`原有的机位、人物动作与面部神态完全不变，将`[@视频1]`中人物身穿的外套替换为`[@图片1]`中的米白色针织开衫，背景光线保持自然柔和。

## 3. `audio: false` 静音机制与声画控制

1. **非口播/非音效镜一律传 `audio: false`（CLI `--no-audio`）**：
   - Seedance 2.0 / 2.5 默认会自动配乐、配环境音甚至让画面人物张嘴念随机台词。
   - 小云雀服务端无底层静音布尔字段；传 `audio: false` 时，插件自动在提示词末尾追加 `"（全片无对白、无旁白、无背景音乐，静音）"`，能大幅抑制人物误张嘴说话和杂乱 BGM。
   - **后期兜底**：下载后的 MP4 只要不需要保留原生语音，进剪辑线前统一加 `ffmpeg -an` 剥离音轨。
2. **需要原生口播或环境音效时**：
   - 传 `audio: true`（默认），并在提示词里用引号写明台词内容、语速与情绪，例如：`人物正对镜头自然微笑说道：“这款便携咖啡杯真的很轻便。”吐字清晰，口型同步，室内安静无背景音乐`。

## 4. 写实画面稳定度与审核规避要点

- **锁定机位减少畸变**：实拍感短视频明确写出 `"固定机位，镜头不推不拉不移动"`（或仅单一缓慢运镜，如 `"镜头缓慢平稳向右横移"`），避免同时叠加推拉摇移导致背景融化。
- **真实物理尺寸锚定**：人货同框时写清产品相对人体部位的真实比例（如 `"高约 15 cm，握在单手掌心中"`），防止模型把小物件放大成抱枕尺寸；若 `reference` 连续失真，先合成准确比例的静态首帧图改走 `first_last_frame`。
- **规避 `99999` 侵权拦截**：不要在提示词中写“像某明星”、“像同一真人身份”或著名商业品牌名；描述同一角色跨镜头一致时写 `"保持与[@图片1]一致的发型、穿搭与整体气质"`。
- **特殊模型格式边界**：
  - 用 `wan3.0` 时图片先压缩至 **20 MB 以内**且转为 `png`/`jpg`/`webp`（禁传 `gif`），参考视频裁短使 `参视秒数 + 输出秒数 <= 30`。
  - 用 `happyhorse-1.1` 时显式指定画幅（如 `16:9` 或 `9:16`，勿用 `adaptive`），勿传 `seed`、`first_frame`、`last_frame`、`bmp` 或 `gif`。
