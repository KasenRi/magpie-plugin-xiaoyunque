# 小云雀生成片段抽帧与运动量质检规范（QA）

生成完成的 MP4 片段必须经过客观指标与关键帧目视双重质检，确认合格后方可进入成片剪辑线。

## 1. 运行 `scripts/qa_clip.py`

对单条 MP4 或整个 `$WORK/clips_raw/` 目录运行：

```bash
python3 "$SKILL_DIR/scripts/qa_clip.py" "$WORK/clips_raw/" -o "$WORK/qa_out"
```

脚本对每条视频自动产出三项结果：
1. **`<stem>_strip3.jpg`（首 / 中 / 末三帧横条）**：快速检查构图稳定性、主体是否出画、有无意外运镜或字幕贴纸。
2. **`<stem>_first_last_full.jpg`（1:1 全分辨率 `[首帧 | 末帧 | 4x 差分图]`）**：放大检查主体缓慢膨胀/缩水、五官手部崩坏、背景结构漂移等缩略图不易察觉的瑕疵。
3. **终端 JSON 报告（含 `tblend` 帧间运动量与异常标记）**：
   - `NEAR_STATIC_STILL_FRAME`：`step_yavg_mean < 0.30` 且首末像素变化率极低，说明生成成了近乎静止的假视频（PPT 感）。
   - `HIGH_MOTION_OR_CAMERA_MOVE`：`step_yavg_mean > 4.5` 或边缘剧烈变化，固定机位镜头出现违规大幅晃动或切镜闪烁。
   - `SUBJECT_GROWTH_OR_BLOOMING`：帧间步进很小但中心区域单调累积漂移显著，常见于植物异常生长开花或物品缓慢变形。
   - `HAS_AUDIO_STREAM`：MP4 含有音轨；由于小云雀 `audio: false` 为提示词静音，若成片使用外部配音/BGM，合成时记得加 `ffmpeg -an` 剥离源音轨。

---

## 2. 目视质检必查清单

打开 `_strip3.jpg` 与 `_first_last_full.jpg` 逐项核对：
- **主体与手物交互**：手指根数与关节正常，手握物品无穿插、无凭空多出第二件产品或悬浮物。
- **真实尺寸比例**：以成年人头部（高约 22–24 cm）或手掌（宽约 8–9 cm）为标尺，检查同框产品没有被夸张放大或缩小。
- **口型与神态**：非口播镜人物未无故张嘴念词；口播镜人物口型开合自然、眼神不呆滞乱飘。
- **画面纯净度**：四角与底部无乱码伪字幕、无第三方平台水印、无多余切镜黑场。

---

## 3. 局部挽救与返工决策树

1. **前好后崩 / 后好前崩**：若 5 秒片段中有连续 2.5–3 秒动作自然无瑕疵，优先用 `ffmpeg -ss ... -t ...` 裁出合格区间直接采用（0 积分损耗）。
2. **构图与比例从第 1 帧就错**：不要用相同提示词在 `reference` 模式反复盲抽；先用生图工具或修图固定好首帧构图，改用 `mode: "first_last_frame"`（`--first-frame`）锁死起点。
3. **高成本模型返工先降级探路**：若 `Seedance_2.5` `1080p` 运动方向不对，先切回 `Seedance_2.5_draft`（9 积分/秒）调通提示词拿到满意样片，再用 `draft_task_id` 转正。
4. **返工上限**：同一分镜最多返工 **3 次**（连首试最多 4 条计费生成），每次返工通过 `--rework-reason` 写明具体问题与参数调整点。
